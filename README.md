# 🧠 Logic Calculator

A simple propositional logic calculator built with
HTML, CSS, and vanilla JavaScript.

## Features

- T / F truth values
- Lowercase variables
- AND `∧`
- OR `∨`
- NOT `¬`
- XOR `⊕`
- Implication `→`
- Equivalence `↔`
- Parentheses
- Live evaluation
- T/F variable controls
- Keyboard shortcuts
- Mobile-friendly interface

## Keyboard shortcuts

| Keyboard | Operator |
|----------|----------|
| `&` | `∧` AND |
| `|` | `∨` OR |
| `!` | `¬` NOT |
| `^` | `⊕` XOR |
| `->` | `→` IMPLIES |
| `<->` | `↔` EQUIVALENT |
